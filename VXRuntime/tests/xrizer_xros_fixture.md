# Owned visionOS simulator xrizer fixture

This is an opt-in simulator development fixture. It connects the existing `VXImmersiveRenderer` to static xrizer, the Klepton provider and the Windows guest bridge. The offscreen option injects a labelled identity head, disconnected controllers and symmetric ±π/4, ±32 mm eye geometry. Drawable timing and the Metal device/queue come from the existing compositor. The simulator's mono drawable is left on the existing clear path; it is not described as stereo presentation or real head/controller tracking. Callback contexts remain alive for the process lifetime.

The optional build is `XRIZER_RUST_ROOT=<repository-local toolchain> make -C VXRuntime XROS_SDK=xrsimulator XROS_XRIZER_FIXTURE=1 XROS_CODE_SIGNING=NO xros-app`. Select the fixture and offscreen producer separately with `VXRT_XRIZER_XROS_FIXTURE=1` and `VXRT_XRIZER_XROS_OFFSCREEN=1`, and run the owned `xrizer_xros_guest` test. The xros AOT helper's optional output root is confined to this checkout's `VXRuntime/build` and the ordinary default remains `build/$SDK`. The fixture target uses its own AOT, bundle, guest, thunk and generated Xcode project directories. The corrected target built successfully in fresh root `IjXWil`; an independent hash inventory confirmed that 72 files under the ordinary `build/xros/t` and `build/xros/bundle` were unchanged. Its first package used the wrong resource folder name and was rejected without launch; the corrected package contained the expected guest executable under `bundle/exe`.

The owned MSVC guest queries actual provider geometry before its first frame, selects seated tracking, creates D3D11 textures, submits two distinct stereo pairs and calls a statically thunked guest audit export. The audit reads the provider's completed offscreen pair, verifies each 4×3 eye's pixel values, frame/pose IDs and reader lease, then drains readers before guest shutdown. It does not read drawable pixels. The existing presenter separately logs command-buffer completion status when the real stereo path draws.
